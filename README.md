# TIMESERIES_BOOK · 工业时序模型训练

中英双语的「工业时序模型训练」自学教程 —— 面向要真的把预测模型训出来、并且让它在厂里活下去的人。

**9 个模块 / 30 章 / 170 小时**,每章由三块组成:

- **时序台**:一个可交互模拟器,所有数字在你的浏览器里现算 —— 真实的岭回归求解、真实的自相关、真实的直方图梯度提升树、真实的死区压缩与分位数回归。没有一张是画出来的假图。
- **解释**:讲清机制、代价和边界。
- **代码**:Python / 数据与配置 / 训练与部署 三个视角,90 段可读长度的完整片段。

全书以一座工厂的电力负荷作为贯穿始终的例子 —— 数据好拿、后果好算、周期性明显 —— 但方法适用于能耗、温度、振动、流量、产量与质量。

## 关于「所有数字现算」

这不是一句宣传。时序台里跑的是:

- **正规方程 + 高斯消元**的岭回归(viz.jsx 的 `ridge`)
- **直方图梯度提升树**,预分箱后按箱扫描找分裂点(t12,LightGBM 的思路)
- **分位数回归**的次梯度下降(t13)
- **随机傅里叶特征**做容量旋钮,展示真实的过拟合曲线(t15)
- **死区 + 扫描周期**的历史库压缩重放(t4)
- **自相关、Ljung-Box、PSI、Spearman、Erlang 风格排队**等等

`rng()` 用的是 mulberry32 而不是常见的 xorshift32:后者在被 `gauss()` 成对消耗之后,低概率抽样会出现明显相关(实测 930 次 p=0.008 的抽样只命中 1 次,期望 7.4),这会悄悄扭曲每一个蒙特卡洛台子。

## 已知的取舍

- t16 的架构对比诚实地报告实测结果:在这份数据上参数最多的直接线性最好,DLinear 与 Patch 线性并未反超。真正的结论是三者相差不到两个点,而它们全体距离零参数的季节朴素只有一个多点 —— 在这条产线上,架构不是误差所在的地方。
- t17 用「在别的工厂语料上训练、零样本迁移到你这条线」来演示基础模型的决策链。这是真实可算的迁移学习,但它不是 Chronos/TimesFM 本身;真模型请用该章代码里的 `zeroshot.py`。
- t15 的容量旋钮是随机特征 + 岭回归而非神经网络。过拟合的机制与曲线形状是同一件事,章内已注明。
- 平台价格与配额(t21)变化很快,以各家官网为准。
